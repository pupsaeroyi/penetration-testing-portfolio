# HTB Cap

**Platform:** Hack The Box · **Difficulty:** Easy · **OS:** Linux

## Two reports per lab

- [Professional pentest report](HTB_Cap_Professional_Pentest_Report.md): scope, findings, evidence, impact, remediation, and limitations.
- [Learning walkthrough](HTB_Cap_Full_Learning_Walkthrough.md): commands, reasoning, mistakes, and lessons.

Both files were copied unchanged from the supplied reports. They describe a training lab, not a client engagement. They document user access and a confirmed root shell; root flag retrieval/submission is not documented.

## Supporting artifacts

- `scans/`: this machine's original scan output.
- `screenshots/`: redacted supporting screenshots.

These folders start empty. Evidence referenced in the supplied reports has not been independently imported or verified.
