# HTB Enigma

**Platform:** Hack The Box · **OS:** Linux

- [Professional pentest report](HTB_Enigma_Professional_Pentest_Report.md)
- [Learning walkthrough](HTB_Enigma_Full_Learning_Walkthrough.md)

The supplied reports describe an authorized training lab. They document access to a Linux user account and disclosure of a root-protected file through command injection. A persistent root shell and the user flag value were not captured in the supplied evidence.

The `scans/` and `screenshots/` folders are for supporting artifacts. Original evidence has not been imported or independently verified.

Reusable notes are available for [Nmap](../../../tools/nmap.md) and [Kali Linux and shell commands](../../../tools/kali-linux.md).
